# Architecture decision records

One file per decision that shapes more than one story, numbered in the order it
was taken: `NNNN-short-title.md`. Each states the context it was decided in,
the decision itself, and the consequences we are accepting — including the ones
we would rather not.

A record is not revised when we change our minds. A new record supersedes it
and says which one it replaces, so the reasoning behind a shape still in the
code is never quietly edited out from under it.
